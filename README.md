# 🧘‍♀️ Yoga Journey (Landing Page)

## Overview
One of my very first coding milestones from 4 years ago. This project is a responsive frontend landing page built as part of the SheCodes workshops, exploring the fundamentals of web development, layout design, and user interaction.

## Technologies Used
* **Frontend**: HTML5, CSS3
* **Design**: Responsive Layouts, Typography 
* **Coursework**: SheCodes Workshop

## Key Features
* Clean, semantic HTML structure for yoga articles and sections
* Call-to-Action (CTA) integration designed to engage users beginning their mindfulness journey
* Responsive elements tailored for text-heavy content (Psychology, Mental Health, Svadhyaya)
